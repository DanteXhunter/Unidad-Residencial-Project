# Unidad Residencial Project

Aplicación web escolar para la administración de unidades residenciales, asignada como tarea para **Héctor**.

## Descripción

El proyecto consiste en desarrollar una app web que permita administrar una unidad residencial (condominio, conjunto de apartamentos, etc.), cubriendo operaciones CRUD sobre sus entidades principales y un sistema de autenticación de usuarios.

## Requisitos de la tarea

- [ ] App Web (frontend + backend)
- [ ] Mínimo 6 tablas en la base de datos
- [ ] CRUD completo sobre las entidades principales
- [ ] Autenticación (Auth)
- [ ] Funcionalidad de administración de unidades residenciales

## Alcance

Aún no está definido el modelo de datos ni la arquitectura. Como punto de partida, algunas tablas candidatas para cumplir el mínimo de 6 son:

1. Usuarios
2. Roles / permisos
3. Residentes / propietarios
4. Unidades (apartamentos, casas)
5. Pagos / cuotas
6. Visitantes o mantenimientos

> Esta lista es solo una propuesta inicial y puede cambiar conforme se defina el diseño.
